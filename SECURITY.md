# Security and responsible disclosure

This repository contains research code only. It must not be used to make clinical,
diagnostic, prescription, or treatment decisions.

Please do not open a public issue containing credentials, private training examples,
restricted benchmark questions, model weights, or patient information. Report a
security issue through GitHub's private security-advisory interface for this repository.

The public tree intentionally excludes raw datasets, per-example predictions, model
weights, optimizer state, checkpoints, cloud credentials, and private interview notes.
